# proyecto-depurador-visual
Plataforma de apoyo a la comprensión de estructuras iterativas para programadores noveles empleando depuración visual

Funcionalidades provisorias:

    CRUD de códigos
    Login (Usuarios: Profesor - Estudiantes)
    Compilador (Ejecución del código-Control de ejecución)
    Depurador Visual
    Revisión del código por parte del profesor
    CRUD ejercicios del profesor (módulo profesor y estudiante)
